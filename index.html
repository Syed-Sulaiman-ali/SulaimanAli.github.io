01 SAP ABAP · Open SQL · Internal Tables

ABAP Database Synchronization Using MODIFY

A synchronization program that uploads 15 records from a file into an internal table, compares them with database table ZSTUDENT123, and classifies every record before updating the database.

Problem

Bulk-loading file records directly into a database table can overwrite unchanged rows or leave no visibility into what was inserted versus updated.

Approach

Loaded the 15 file records into an internal table, fetched existing entries from ZSTUDENT123 using Open SQL, compared fields row by row, and applied MODIFY only where needed.

Result

New records are inserted, modified rows are updated, unchanged rows are flagged, and each record is clearly classified as NEW, CHANGED, or NO CHANGE.

ABAP Snippet & Sync Status
READ TABLE lt_db INTO ls_db
  WITH KEY student_id = ls_file-student_id.

IF sy-subrc <> 0.
  ls_log-status = 'NEW'.
  MODIFY zstudent123 FROM ls_file.
ELSEIF ls_db <> ls_file.
  ls_log-status = 'CHANGED'.
  MODIFY zstudent123 FROM ls_file.
ELSE.
  ls_log-status = 'NO CHANGE'.
ENDIF.
NEW CHANGED NO CHANGE

03 Windows Troubleshooting · System Recovery

Windows System Recovery and Troubleshooting

Recovered a Windows laptop frozen at the login screen using System Restore, then diagnosed a secondary Google Chrome startup issue that appeared after recovery.

Problem

A Windows laptop hung completely at the login screen, blocking normal desktop access, and later showed a Chrome startup issue after booting.

Approach

Entered recovery options, selected a valid restore point via System Restore to roll back system state safely, then isolated the Chrome startup issue step by step.

Result

Restored normal Windows login and desktop access without wiping user data, followed by targeted diagnosis of the post-restore browser issue.
